## 🔴 Ransomware Detection, Family Classification & Severity Prediction

An MSc Cybersecurity research project focused on behaviour-based ransomware analysis using Sysmon logs, behavioural feature extraction and machine learning.

### Key Contributions

- Built an isolated VMware-based environment for controlled ransomware execution.
- Collected behavioural information using Microsoft Sysmon.
- Extracted process, file, registry and DNS-related behavioural features.
- Developed behaviour-based severity scoring.
- Built a Random Forest severity prediction model.
- Built a Random Forest ransomware-family classification model.
- Developed a Streamlit dashboard for analyst-facing results.
- Mapped observed behaviours to relevant MITRE ATT&CK categories.

### Results

- Severity prediction accuracy: **96.88%**
- Ransomware family classification accuracy: **93.75%**

### Technologies

`Python` `Sysmon` `VMware` `Scikit-learn` `Random Forest` `Pandas` `Streamlit`
